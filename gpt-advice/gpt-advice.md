需求：实现歌词驱动的 SVG 动态性别仪表盘
======================

请根据我提供的三张参考图，实现一个网页中的 SVG 动画组件。参考图展示的是同一个画面在不同时间节点的状态，不能将它们当作三个独立的静态图片。
一、视觉风格
------

* 深蓝色背景，接近参考图的暗蓝色。

* 所有图形、文字和线条使用白色或半透明白色。

* 画面整体为极简、科技感、复古仪表盘风格。

* 中心的男女合并符号、圆形刻度盘、指针和文字都应该使用 SVG 矢量图形。

* 动画区域应当铺满可用画布，中心始终保持在画面正中央。

* 参考图中存在类似扫描线的视觉纹理，如需复现可以使用 SVG pattern 或 CSS，但不要影响主要图形的清晰度。

二、动画流程
------

这是一个由歌词驱动的连续动画，歌词为：

from F to M

整个动画按照以下顺序执行。

### 阶段 1：初始状态

画面显示一个中央的男女符号，左侧为女性符号，右侧为男性符号，两个符号逐渐靠拢并合并。

合并后的符号应当保持参考图中的外观：女性符号的圆形和十字部分，以及男性符号的右上方箭头，形成一个完整的中心性别符号。

初始阶段不要显示完整的仪表盘，也不要显示 100% 数字。

### 阶段 2：从中心泛起同心圆

男女符号合并完成后，以合并符号的中心为圆心，逐渐出现同心圆扩散效果。

要求：

1. 从中心向外产生圆形波纹。

2. 圆环由小变大，并逐渐显现。

3. 可以使用 SVG circle 的 stroke-dasharray、stroke-dashoffset 或 CSS 动画实现。

4. 最终形成参考图二所示的圆形仪表盘结构。

5. 动画要有连续性，不能直接瞬间切换成完成状态。

### 阶段 3：外圈刻度和中心指针出现

同心圆扩散后，逐渐显示：

* 外侧大圆环。

* 外圈均匀分布的短刻度线。

* 中央的圆形性别符号。

* 中心指针或刻针。

* 中央百分比文字。

参考图二中，指针为从中心向右上方延伸的白色箭头，刻度环围绕中央符号排列。

初始百分比为 0%。

### 阶段 4：指针旋转至 100%

仪表盘完整出现后，中央指针开始顺时针旋转，最终到达 100% 的位置。

要求：

* 指针从 0% 对应的位置开始。

* 旋转中心必须是中央性别符号的圆心。

* 指针的长度、箭头样式、粗细保持参考图一致。

* 中央百分比文字与指针角度同步变化。

* 旋转过程平滑，不要跳帧。

* 到达 100% 后短暂停留，等待歌词进入下一段。

这里的 100% 是仪表盘动画的完整状态，不代表歌词中 F 或 M 的最终值。

### 阶段 5：歌词 from F to M

当歌词进入 from F to M 时，按照下面的时间轴控制指针和百分比。

#### from

画面保持仪表盘完成状态，指针处于 100%，中央显示 100%。

#### F

当歌词唱到 F 时，指针从 100% 平滑移动到 50%，中央数字从 100% 逐渐变化为 50%。

这个阶段需要明显表现出指针回落到中间位置。

#### to

指针保持在 50%，中央显示 50%。

#### M

当歌词唱到 M 时，指针从 50% 平滑移动到 100%，中央数字从 50% 逐渐变化为 100%。

最终画面必须与参考图三的完成状态一致：指针回到 100%，外圈仪表盘完整，中央数字显示 100%。
三、动画实现要求
--------

请使用 HTML + CSS + SVG + JavaScript 实现，不要使用 Canvas 作为主要绘图方式。

SVG 中的主要元素建议拆分为：

* `gender-symbol`：中心男女合并符号。

* `ripple-rings`：中心泛起的同心圆。

* `gauge-ring`：外圈仪表盘。

* `gauge-ticks`：外圈刻度。

* `gauge-needle`：中心旋转指针。

* `percentage-text`：中央百分比文字。

所有动画应该通过 CSS transition、CSS keyframes 或 JavaScript requestAnimationFrame 实现。

指针旋转角度、百分比数值、动画时间应该集中在可配置的变量中，方便我后续根据真实音频调整。
四、歌词时间控制
--------

不要仅仅使用固定的 setTimeout 模拟歌词。请设计一个可扩展的歌词同步接口，例如：
    const lyrics = [
      { text: "from", time: 0 },
      { text: "F", time: 1000 },
      { text: "to", time: 2000 },
      { text: "M", time: 3000 }
    ];

其中 time 为毫秒，代表歌词开始的时间点。

请实现一个 `setLyricTime(time)` 或类似的函数，根据当前音频播放时间更新仪表盘状态：

* from：保持 100%。

* F：移动到 50%。

* to：保持 50%。

* M：移动到 100%。

后续我会把真实音频和歌词时间传入这个组件，所以代码必须支持通过外部时间驱动，而不是只播放一次固定动画。
五、交付内容
------

请提供：

1. 完整可运行的 HTML 文件。

2. SVG 图形和动画的完整代码。

3. 歌词同步控制的 JavaScript 代码。

4. 可修改的动画时长、指针角度、刻度数量、颜色和字体配置。

5. 说明如何替换为真实音频以及如何设置 F 和 M 的时间点。

请先完成一个能在浏览器直接打开的单文件版本，再考虑拆分为组件。
