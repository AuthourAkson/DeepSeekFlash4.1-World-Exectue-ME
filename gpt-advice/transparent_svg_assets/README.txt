这两个 SVG 是根据用户提供的两张 PNG 截图进行前景矢量化得到的。

文件：
1. crown_gauge.svg
   - 皇冠
   - 中间的两条水平椭圆/波纹线
   - 其它截图中检测到的浅色前景元素
   - 已移除深蓝色背景

2. crossed_symbol.svg
   - 下方交叉符号
   - 中间的两条水平椭圆/波纹线
   - 其它截图中检测到的浅色前景元素
   - 已移除深蓝色背景

SVG 使用透明背景，前景为可编辑的 path。
注意：截图本身带有明显的显示扫描线/纹理，因此这里进行了轻微去噪和矢量轮廓化，
以便作为网页 SVG 动画素材使用。若要 1:1 保留扫描线纹理，建议把纹理作为 CSS/SVG pattern
单独叠加，而不要把扫描线直接烘焙进路径。
